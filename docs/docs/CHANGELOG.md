AIRAC 2609:

It's that time of month again! Some major changes are here! Firstly the most obvious one is that we have revamped the Manila and Mactan Ground view to replicated the real ground view! Secondly I have introduced a custom plugin that auto assigns the SIDs based on their aircraft type, active runway and current scope setup - What does this mean? Well when you change the settings to Non-Radar, then it will auto assign the aircrafts SIDs to the respective SIDs, and if you choose RADAR, then it will assign the runways special altitude and RDVxTMA, Keep in mind this button could be hidden behind the APP Window on ground view! Auto stands now give real world stand assignments! So please use them :) To make some things less confusing, I've renamed the Manila ACC to ACC. And for now the FSS.prf is currently not working due to some issues. If you find any bugs please let me know ASAP so I can release a fix for the issue!
